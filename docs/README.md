## Quick Start

For developers looking to get started quickly:

1. **Setup Environment**: Follow [Setup & Installation](setup.md)
2. **Run the App**: `npm run android` or `npm run ios`
3. **Understand Architecture**: Read [Architecture](architecture.md)
4. **Explore Features**: Check [Features](features.md)
