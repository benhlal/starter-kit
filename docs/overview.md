# AR Coin Hunt - Overview

## Application Purpose

AR Coin Hunt is a mobile augmented reality game that combines GPS-based positioning with AR technology to create an immersive coin hunting experience. Players participate in organized events where they hunt for virtual coins placed in real-world locations using their mobile devices.

## Target Audience

- **Primary Users**: Mobile gamers interested in location-based AR experiences
- **Event Organizers**: Users who create and manage coin hunt events
- **Casual Players**: Those looking for outdoor activities with gamification elements
- **Tech Enthusiasts**: Users interested in AR and GPS technology integration

## Core Features

### 🎯 AR Coin Hunting

- Real-time AR coin visualization using ViroReact
- GPS-based coin placement and proximity detection
- Kalman filtering for improved GPS accuracy
- Coin collection with visual feedback

### 📅 Event Management

- Create and join organized coin hunt events
- Time-based event scheduling (upcoming, ongoing, completed)
- Participant management and scoring
- Late join functionality with penalty fees

### 🗺️ Location Services

- Precise GPS positioning with accuracy optimization
- Map integration for event visualization
- Compass heading for directional guidance
- Location permission management

### 👥 Social Features

- User profiles and participation tracking
- Event leaderboards and scoring
- Real-time participant synchronization
- Community event discovery

### 🔄 Real-time Synchronization

- Firebase Firestore for data persistence
- Real-time updates for event status and participation
- Offline capability with data synchronization
- Cross-device compatibility
